pnpm workspaces + Turborepo. Run `pnpm dev`, test `pnpm test`, build `pnpm build`.

This repo's cross-session context lives in my Obsidian vault at `projects/manyouscript/`.
The vault path is set per-machine in `~/.claude/CLAUDE.md`. Before working, read that
project's `current-focus.md` and `decisions.md`, and record decisions/status back to them.
